This is the [Homebrew](https://brew.sh/) tap for the [Nylas CLI](https://github.com/nylas/cli) — built on [Nylas](https://developer.nylas.com/), the infrastructure that powers communications. Covers [Agent Accounts](https://developer.nylas.com/docs/v3/agent-accounts/), [Email](https://developer.nylas.com/docs/v3/email/), [Calendar](https://developer.nylas.com/docs/v3/calendar/), [Contacts](https://developer.nylas.com/docs/v3/email/contacts/), [Scheduler](https://developer.nylas.com/docs/v3/scheduler/), and [Notetaker](https://developer.nylas.com/docs/v3/notetaker/).

## Install

```bash
brew install nylas/nylas-cli/nylas
```

Then get started:

```bash
nylas init
```
